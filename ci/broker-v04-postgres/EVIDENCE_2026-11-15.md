# Isolated qualification evidence — 2026-11-15

The [GitHub Actions run](https://github.com/dragonballzsubzero/GPTprime-a2a-gateway/actions/runs/43750663414) tested source commit `23652a46df63c337b3ac088d6eaaba585cfbb1b4` in disposable GitHub-hosted environments. These are development checks, not a production release approval.

- PostgreSQL 17.6 executed the v0.4 candidate using synthetic tables and a simplified trust gate. Sixteen independent clients produced one effect for the same nonce. A forced server crash preserved the committed nonce/effect and rolled back an uncommitted nonce. The suite also exercised key revocation, quarantine, expiration while waiting, and API-role denials. It explicitly confirmed that the invoker function cannot work with a caller lacking direct table privileges; the production authorization boundary therefore needs redesign.
- A rootful Docker daemon exercised a staged snapshot after the original input changed, archive traversal rejection, non-root UID, dropped capabilities, read-only mounts and a failed outbound connection. The production wrapper rejected this rootful daemon.
- A separate Docker 28.3.3 rootless daemon exercised the actual wrapper with a digest-addressed built image and rejected an archive traversal with a failing process status. The CI host changed its own user-namespace setting and used a deliberately incomplete, test-only seccomp profile. This result does not establish that a production host has safe settings, reviewed seccomp, enforced resource limits or resistance to escapes.
- An earlier [rootless attempt](https://github.com/dragonballzsubzero/GPTprime-a2a-gateway/actions/runs/43750479584) started the daemon but failed to start a container because the CI runner lacked user cgroup delegation. A still earlier attempt lacked the expected Docker package. Both failures were retained in CI history; the passing run used an explicitly delegated user session.

The live database and deployment were not modified by these tests. External audit operations, privileged-credential separation, real owner enrollment, production host qualification and a live authorized effect remain open. Model smoke evidence is recorded separately in `ci/broker-v04-model-eval/EVIDENCE_2026-11-15.json`.
